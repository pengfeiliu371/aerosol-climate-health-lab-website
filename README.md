# Aerosol, Climate & Health Laboratory Website

This repository contains the public website for the Aerosol, Climate & Health Laboratory at Georgia Tech.

- [View the published website](https://pengfeiliu371.github.io/aerosol-climate-health-lab-website/)
- [Manual content-editing guide](CONTENT_EDITING_GUIDE.md)

Most routine updates—news, people, publications, research areas, datasets, and photographs—can be made directly in the GitHub web interface without using Codex or installing software.

## Local development

```bash
npm install
npm run dev
npm run build:pages
```

Changes merged into `main` are automatically built and deployed through GitHub Actions.
